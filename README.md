# Day-Trading-Prediction-Machine
Analyzing Market Trends to Predict Whether to Buy or Sell

## Initial Scope:
**Assets**: SPY
**Bar Size**: 5 minute bars 
**Holding rule**: Flat by end of day so there is no overnight risk
**Objective**: Predict the next 5 minute return direction (up or down)
**Constraints**: 
- Fixed transaction cost 
- Max position = +/- 1 unit
